# Charm the Commuter: Forecast a City That Isn't

One line of weather forecast — at most 140 characters — for a city that
doesn't exist, written to make a bored commuter smile on the way to work.

> Good morning, Nimbustown — 22°C, light drizzle, and the 8:12 bus is somehow on time. Bring a brolly, leave the grump at home.

`main.ts` (Node 22, stdlib only, no network) writes the line to
`entry.txt`, validating it is a single line of 1–140 characters.
Deterministic: the same output on every run.
